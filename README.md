# Qissa Khawani — website demo

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Updates in this version

- Updated the three branch addresses, branch-specific phone links, Foodpanda links, and Google Maps search links.
- Changed the story direction to evoke Peshawar's Qissa Khwani Bazaar and shared dastarkhwan culture.
- Corrected menu tab grouping to match the six supplied category names (rather than mislabelling naan and sides as biryani/nihari).
- Added a buffet-by-special-booking enquiry section.
- Removed misleading five-star visuals and invented guest quotes; each branch now links to Google review search results.
- Added the supplied Facebook and Instagram links.
- Updated Next.js to the patched 15.5.28 maintenance release and React 19 dependencies.
